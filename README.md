# 📰 Fake News Detection using Machine Learning

- This project uses Machine Learning techniques to classify news articles as Fake or Real


## 📌 Project Overview

- The model analyzes news content (title + text)
- Predicts whether the news is Fake or Real
- Fake News - 1
- Real News - 0
- Uses Natural Language Processing (NLP)


## 📊 Dataset

- Fake.csv - Fake news articles
- True.csv - Real news articles
- Combined dataset is used for training
- Label column:
  - 1 - Fake
  - 0 - Real


## ⚙️ Workflow

- Data Loading
- Data Preprocessing
- Feature Extraction using TF-IDF
- Train-Test Split
- Model Training
- Model Evaluation
- Prediction System


## 🧠 Models Used

- Logistic Regression
- Support Vector Machine (SVM)


## 📈 Results

- Logistic Regression Accuracy - ~90%
- SVM Accuracy - ~92% to 98%


## 📊 Visualization

- Confusion Matrix (SVM model)
- Displays correct and incorrect predictions


## 🧪 Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn


## 🔮 Prediction System

- Input news text
- Output:
  - Fake News
  - Real News
